FAQ

Is this Bluetooth or Wi-Fi?

Neither. It’s short-range RF with rolling codes. Your door doesn’t need the internet to open.

What about replay attacks?

Rolling codes rotate on each press. Replaying an old capture won’t pass verification.

Can I install it in a rental?

Yes. Start with the Clip-On Module—no drilling. You can upgrade later.
